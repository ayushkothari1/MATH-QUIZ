# Simple Math Quiz

A responsive browser quiz for practicing arithmetic. Questions are generated by an Express backend, and answers are checked on the server.

## Features

- Addition, subtraction, multiplication, division, or mixed questions
- Easy, medium, and hard difficulty settings
- Quizzes of 5, 10, 15, or 20 questions
- Progress and score tracking with correct and incorrect feedback
- Server-side answer checking; question IDs expire after 30 minutes and can be answered once

## Tech stack

- HTML, CSS, and vanilla JavaScript
- Node.js and Express 5
- Node.js built-in test runner

## Install and run locally

Requirements: Node.js 18 or newer and npm.

```sh
npm install
npm start
```

Open <http://localhost:3000>. For automatic server restarts during development, run `npm run dev` instead. Set the `PORT` environment variable to use a different port.

## Production build

```sh
npm run build
npm test
```

The build script checks the server and browser JavaScript syntax. Vercel can detect the Express app from the root `server.js`; static files are kept in `public/` for hosting. No custom Vercel configuration is required.

## Quiz flow

The browser requests a question from `GET /api/question` using the selected category and difficulty. The server generates it and stores its answer against a temporary question ID; the answer is not included in the response. When the user submits a number, the browser sends it with the ID to `POST /api/answer`. The server checks and consumes that ID, and returns whether the answer is correct. The browser updates the feedback, score, and progress before continuing or showing the final score.
